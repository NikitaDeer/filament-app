# План улучшения сайта: Контент и FAQ

## Общая концепция

Создаем гибкую систему управления контентом, которая позволит администратору редактировать весь текст и изображения на сайте через удобную админ-панель Filament. Система будет поддерживать версионность (черновики + опубликованная версия), что позволит готовить изменения заранее и публиковать их одним кликом.

## 1. Система управления контентом (CMS)

### 1.1 База данных

**Миграция: `create_content_blocks_table.php`**

Создаем таблицу `content_blocks` для хранения всех текстовых блоков и изображений:

- `id` - уникальный идентификатор
- `key` - уникальный ключ блока (например, `home.hero.title`, `about.company.description`)
- `page` - страница (home, about, services, vehicles, prices, contacts, faq)
- `section` - секция страницы (hero, advantages, about, fleet и т.д.)
- `type` - тип контента (text, textarea, image, rich_text)
- `label` - человекочитаемое название для админки
- `value` - текстовое значение (для text, textarea, rich_text)
- `image_path` - путь к изображению (для type=image)
- `order` - порядок сортировки
- `is_published` - опубликован ли блок
- `published_at` - дата публикации
- `metadata` - JSON для дополнительных параметров (alt для картинок, классы и т.д.)
- `timestamps`

**Миграция: `create_content_versions_table.php`**

Создаем таблицу `content_versions` для хранения истории изменений:

- `id`
- `content_block_id` - связь с блоком
- `value` - значение
- `image_path` - путь к изображению
- `is_published` - была ли эта версия опубликована
- `created_by` - кто создал (user_id)
- `published_at` - когда опубликовано
- `timestamps`

### 1.2 Модели

**`app/Models/ContentBlock.php`**

- Связь `hasMany` с `ContentVersion`
- Scope `published()` - только опубликованные
- Scope `forPage($page)` - для конкретной страницы
- Scope `forSection($section)` - для конкретной секции
- Метод `getPublishedVersion()` - получить опубликованную версию
- Метод `getDraftVersion()` - получить черновик
- Метод `publish()` - опубликовать текущий черновик
- Accessor `value_or_default` - возвращает значение или дефолтное

**`app/Models/ContentVersion.php`**

- Связь `belongsTo` с `ContentBlock`
- Связь `belongsTo` с `User` (created_by)

### 1.3 Filament Resource

**`app/Filament/Resources/ContentBlockResource.php`**

Создаем удобный интерфейс с фильтрацией по страницам и секциям:

- Форма:
  - `Select` для выбора страницы (home, about, services и т.д.)
  - `Select` для выбора секции (hero, advantages и т.д.)
  - `TextInput` для key (автогенерация на основе page.section.field)
  - `TextInput` для label
  - `Select` для type (text, textarea, image, rich_text)
  - Conditional fields:
    - Если `type=text`: `TextInput` для value
    - Если `type=textarea`: `Textarea` для value
    - Если `type=rich_text`: `RichEditor` для value
    - Если `type=image`: `FileUpload` для image_path с preview
  - `Toggle` для is_published
  - `KeyValue` для metadata
- Таблица:
  - Колонки: page, section, label, type, is_published, published_at
  - Фильтры: по страницам, секциям, типу, статусу публикации
  - Actions: 
    - "Опубликовать" (если черновик)
    - "Создать черновик" (создать копию для редактирования)
    - "История версий" (modal со списком версий)
- Bulk Actions:
  - "Опубликовать выбранные"
  - "Снять с публикации"

### 1.4 Seeder

**`database/seeders/ContentBlockSeeder.php`**

Создаем начальные блоки контента для всех страниц со значениями по умолчанию из текущих Blade-файлов:

- Главная: hero заголовок, подзаголовок, hero-изображение, преимущества (3 блока), о компании, статистика
- О компании: заголовок, описание, преимущества
- Услуги: hero заголовок, описание
- Автопарк: hero заголовок, описание
- Цены: hero заголовок, описание, условия работы
- Контакты: заголовок, описание
- FAQ: заголовок, описание

### 1.5 Helper

**`app/Helpers/ContentHelper.php`**

Создаем helper-функцию для удобного получения контента в Blade:

```php
function content($key, $default = '') {
    return \App\Models\ContentBlock::where('key', $key)
        ->where('is_published', true)
        ->first()?->value ?? $default;
}

function content_image($key, $default = '') {
    return \App\Models\ContentBlock::where('key', $key)
        ->where('is_published', true)
        ->first()?->image_path ?? $default;
}
```

Регистрируем в `composer.json` autoload.files

## 4. Рефакторинг всех страниц для использования ContentBlock

### 4.1 Заменить жестко закодированный текст

Во всех Blade-файлах заменить текст на вызовы helper-функции `content()`:

**Было:**

```blade
<h1 class="...">Надежные грузоперевозки в СПБ и ЛО</h1>
```

**Стало:**

```blade
<h1 class="...">{{ content('home.hero.title', 'Надежные грузоперевозки в СПБ и ЛО') }}</h1>
```

**Было:**

```blade
<div class="...">
  <svg ...></svg>
</div>
```

**Стало:**

```blade
@if(content_image('home.hero.image'))
  <img src="{{ asset('storage/' . content_image('home.hero.image')) }}" alt="..." class="...">
@else
  <div class="...">
    <svg ...></svg>
  </div>
@endif
```
